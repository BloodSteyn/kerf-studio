Machine settings

These describe the machine itself and are saved with the machine selected in the header. Values marked $ are read from the controller when you connect.

Work origin is the machine coordinate of the front-left of your bed. It is 0, 0 on most laser firmware. If your machine homes to negative coordinates, home it, jog the head to the front-left corner, then use the button below.

Controller settings differ

Your machine reports values that do not match this profile. Nothing is written unless you tick it, and the previous value is logged to the Console first so you can put it back.
